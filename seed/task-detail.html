Across several screens in the app, some UI text and elements are not displayed clearly: The option titles are positioned too close to the selection circle (radio button). The descriptive text/phrases displayed under options are too small and difficult to read. Some words and phrases are cropped or not fully visible. Text spacing and alignment are inconsistent in some areas, affecting overall readability. Message Character Limit – Error Message Update Current Behavior: When the text entered in the Message Card field exceeds 150 characters, an error message appears. The current error message is unclear and contains the technical field name metadata.message. App Text & UI Color – Apply Baqah Brand Color Current Behavior: Some text, icons, and UI elements across the app are displayed in black, which is inconsistent with the Baqah brand styling.

improve the text layout and readability across the app: Add proper spacing between the selection circle (radio button) and its title/text. Increase the font size of descriptions and secondary text slightly to make them easier to read. Ensure all words and sentences are fully visible and are not cropped or cut off. Allow text to wrap correctly to a second line when there is not enough horizontal space. Maintain proper padding between text, icons, buttons, and other UI elements. Apply the improvements consistently across relevant screens, including: Delivery options Payment methods Cart Product listing/cards Order summary and informational messages Replace the Message Card field exceeds 150 current validation message with a clear, user-friendly message in both Arabic and English. Arabic: يجب ألا تتجاوز الرسالة 150 حرفاً. English: The message must not exceed 150 characters. Change the applicable black UI elements to the existing Baqah brand color: Baqah Color: #505748 This should be applied consistently across the app where black is currently used for primary UI styling, including: Product price Main titles and headings Product names and prices Navigation icons and labels Cart icons and Add To Cart text Other applicable black text/icons Please ensure the change is applied consistently across both Arabic and English interfaces without affecting readability or disabled/error-state colors.
